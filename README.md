# Tom and Jerry UI 🐱🐭

A simple project built with **Jetpack Compose** featuring user interfaces inspired by the famous Tom and Jerry cartoon.

> **Note:** This is a **UI-only** project, designed to showcase layout skills and component distribution in Compose.
